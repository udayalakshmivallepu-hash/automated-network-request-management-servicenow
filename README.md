# automated-network-request-management-servicenow
Automated Network Request Management project developed in ServiceNow.
## Phase 1 – Requirement Analysis & Planning

### Functional Scope

The Automated Network Request Management project will include:

1. Service Catalog
   - Create a Network Request catalog item.
   - Allow users to submit network-related requests.

2. Request Form
   - Capture Request Type.
   - Capture Access Level.
   - Capture Device information.
   - Capture Business Justification.
   - Capture Priority.
   - Dynamically display relevant fields based on the selected request type.

3. Approval Routing
   - Validate request information.
   - Route requests to the appropriate approver.
   - Support approval and rejection.

4. Flow Designer Automation
   - Automate the request lifecycle.
   - Create fulfillment tasks after approval.
   - Assign tasks to the appropriate Network Team.
   - Update request status as tasks progress.

5. Email Notifications
   - Notify approvers when approval is required.
   - Notify requesters about important status changes.
   - Notify requesters when the request is completed.
